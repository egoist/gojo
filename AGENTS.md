# Notes for coding agents

## Documentation

- Write docs as the description of the current design. Say what the language, compiler or tools do, not how they used to work or what changed: no "now", "no longer", "instead of the old ...", "there is no X to keep anymore", and no examples written to contrast with earlier code. A reader should not be able to tell what an earlier version looked like.
- Comparisons with other languages (Rust, Go, Swift, ...) are fine; comparisons with earlier versions of Gojo are not. History belongs in commit messages and in the notes that are about it (`docs/ideas.md`, the "what came later" part of `docs/concurrency.md`).
